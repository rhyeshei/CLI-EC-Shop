# CLI EC Shop

## アプリ概要

商品の閲覧・検索から、カート追加・注文・在庫更新までをCLI上で行えるECアプリケーションです。

## 主な機能

- 商品機能
  - 商品一覧表示
  - 商品名検索
  - 商品詳細表示
- カート機能
  - カートへの商品追加・削除
  - 購入数量の変更
  - 小計・合計金額の計算
- 注文機能
  - 注文内容の確認
  - 注文情報の作成
  - 注文後の在庫更新

## 使用技術

- Java 21
- Eclipse

## クラス構成・役割

### `main`パッケージ

- `Main`
  - アプリ全体の進行や画面遷移を制御
  - 各Serviceクラスのメソッドを呼び出す
- `Menu`
  - コンソールに表示する各種メニューや入力案内を表示

### `model`パッケージ

- `Product`
  - 商品ID・商品名・価格・在庫数を保持
- `CartItem`
  - カートへ追加した商品（`Product`）と購入数量を保持
- `Order`
  - 注文ID・注文日時・注文商品（`List<CartItem>`）・合計金額を保持

### `service`パッケージ

- `ProductService`
  - 商品一覧表示・商品検索・商品取得を行う
- `CartService`
  - カートへの追加・削除・数量変更・合計金額の計算を行う
- `OrderService`
  - 注文情報の作成・合計金額の計算・在庫更新を行う

### `util`パッケージ

- `ConsoleFormatter`
  - 文字の表示幅を計算し、コンソール上の表を整形
- `InputUtil`
  - 入力値を確認し、不正な入力の場合は再入力を求める

## データ設計

### データを表すクラス

- `Product`
  - 商品ID
  - 商品名
  - 価格
  - 在庫数
- `CartItem`
  - 商品情報（`Product`）
  - 購入数量
- `Order`
  - 注文ID
  - 注文日時
  - 注文商品（`List<CartItem>`）
  - 合計金額

### データをまとめて管理するクラス

- `ProductService`
  - `List<Product>`として商品一覧を保持
- `CartService`
  - `List<CartItem>`としてカート内容を保持

## CRUDの対応

| CRUD | 対応機能 |
| --- | --- |
| `Create（作成・登録）` | カート登録、注文情報作成 |
| `Read（読み取り・取得）` | 商品一覧表示、商品検索、商品詳細表示、カート一覧表示 |
| `Update（更新・変更）` | カート数量更新、注文確定時の在庫更新 |
| `Delete（削除）` | カート商品削除 |

## 実行方法

### 必要な環境

- Java 21
- Eclipse

### Eclipseでの実行

1. このリポジトリをクローンまたはダウンロードする
2. Eclipseを起動する
3. `File`から`Import`を選択する
4. `General`の`Existing Projects into Workspace`を選択する
5. ダウンロードしたプロジェクトの`CLI-EC-Shop`フォルダを指定する
6. `src/main/Main.java`を開く
7. `Run As`から`Java Application`を選択する
