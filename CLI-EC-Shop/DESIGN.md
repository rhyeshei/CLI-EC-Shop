# CLI EC Shop

## 演習1：コンセプト設計

| 記入項目 | 内容 |
| --- | --- |
| アプリ名 | CLI EC Shop |
| コンセプト | 商品の閲覧・検索・カート追加・購入・在庫管理など、ECサイトの基本的な購入フローをCLI上で再現するアプリ |
| 作ろうと思った理由 | 内定先がECサイトの総合支援を行う企業であるため、入社前にECサイトの基本構造や、商品・カート・注文・在庫といった主要機能の関係を理解したいと考えたため。 |

## 演習3：ユーザーストーリー

| No. | ユーザーストーリー |
| ---: | --- |
| 1 | 購入者として、商品一覧から商品を探したい。なぜなら、購入したい商品を見つけたいから。 |
| 2 | 購入者として、商品名から商品を検索したい。なぜなら、目的の商品を素早く見つけたいから。 |
| 3 | 購入者として、商品の詳細を確認したい。なぜなら、価格や在庫数を確認して購入するか判断したいから。 |
| 4 | 購入者として、欲しい商品をカートに追加したい。なぜなら、購入予定の商品をまとめて管理したいから。 |
| 5 | 購入者として、カートの商品や数量を確認・変更したい。なぜなら、注文内容に間違いがない状態にしたいから。 |
| 6 | 購入者として、カートの商品を注文したい。なぜなら、商品の購入を確定したいから。 |

## 演習4：機能要件

| No. | 機能名 | 概要 | CRUD |
| ---: | --- | --- | --- |
| 1 | 商品一覧表示 | 登録されている商品を一覧で表示する | `Read` |
| 2 | 商品検索 | 商品名を入力し、条件に一致する商品を表示する | `Read` |
| 3 | 商品詳細表示 | 選択した商品の商品名・価格・在庫数などを表示する | `Read` |
| 4 | カート登録 | 選択した商品と購入数量をカートへ追加する | `Create` |
| 5 | カート一覧表示 | カート内の商品・数量・小計・合計金額を表示する | `Read` |
| 6 | カート数量更新 | カートに登録した商品の購入数量を変更する | `Update` |
| 7 | カート商品削除 | カートに登録した商品を削除する | `Delete` |
| 8 | 注文確定 | カート内容を注文として確定し、商品の在庫数を減らす | `Create / Update` |

### CRUDの対応

| CRUD | 対応機能 |
| --- | --- |
| `Create` | カート登録 |
| `Read` | 商品一覧表示、商品検索、商品詳細表示、カート一覧表示 |
| `Update` | カート数量更新 |
| `Delete` | カート商品削除 |

### メニュー構成

```text
メインメニュー
├─ 1. 商品を探す
│  ├─ 商品一覧表示
│  ├─ 商品検索
│  └─ 商品詳細表示
│     └─ カートに追加
│
├─ 2. カートを見る
│  ├─ カート一覧表示
│  ├─ カート数量更新
│  ├─ カート商品削除
│  └─ 注文確定
│
└─ 0. 終了
```

## 演習5：データ設計

### 商品データ

| 項目名 | 型 | 内容 |
| --- | --- | --- |
| `productId` | `int` | 商品を識別するID |
| `productName` | `String` | 商品名 |
| `price` | `int` | 商品価格 |
| `stock` | `int` | 商品の在庫数 |

```java
class Product {
    int productId;
    String productName;
    int price;
    int stock;
}
```

### カート内商品データ

| 項目名 | 型 | 内容 |
| --- | --- | --- |
| `product` | `Product` | カートへ追加した商品 |
| `quantity` | `int` | 購入数量 |

商品ごとの小計はデータとして保持せず、次の計算で求める。

```java
int subtotal = product.getPrice() * quantity;
```

```java
class CartItem {
    Product product;
    int quantity;
}
```

### カートデータ

| 項目名 | 型 | 内容 |
| --- | --- | --- |
| `items` | `List<CartItem>` | カートへ登録されている商品一覧 |

```java
class Cart {
    List<CartItem> items;
}
```

### 注文データ

| 項目名 | 型 | 内容 |
| --- | --- | --- |
| `orderId` | `int` | 注文を識別するID |
| `orderDate` | `LocalDateTime` | 注文日時 |
| `items` | `List<CartItem>` | 注文した商品一覧 |
| `totalPrice` | `int` | 注文全体の合計金額 |

```java
class Order {
    int orderId;
    LocalDateTime orderDate;
    List<CartItem> items;
    int totalPrice;
}
```

## 演習6：クラス設計

### クラス一覧

| クラス名 | 役割 |
| --- | --- |
| `Main` | プログラムの開始、メニュー制御、各Serviceの呼び出し、終了判定を行う |
| `Menu` | メインメニューや商品メニューなどの表示を行う |
| `ProductService` | 商品一覧表示、商品検索、商品詳細表示などの商品関連処理を行う |
| `CartService` | カートへの登録、一覧表示、数量更新、商品削除、合計金額計算を行う |
| `OrderService` | 注文確定、注文データ作成、商品の在庫更新を行う |
| `Product` | 商品ID、商品名、価格、在庫数などの商品データを保持する |
| `CartItem` | カートへ追加された商品と購入数量を保持する |
| `Cart` | 複数の `CartItem` を保持し、カート全体のデータを管理する |
| `Order` | 注文ID、注文日時、注文商品、合計金額などの注文データを保持する |
| `InputUtil` | `Scanner` を利用した入力受付や数値などの入力チェックを行う |

### 簡易クラス構成

```text
Main
├─ Menu
├─ ProductService
├─ CartService
├─ OrderService
└─ InputUtil

ProductService
└─ Product

CartService
└─ Cart
   └─ CartItem
      └─ Product

OrderService
└─ Order
   └─ CartItem
      └─ Product
```

### 推奨パッケージ構成

```text
src
├── main
│   └── Main.java
│
├── model
│   ├── Product.java
│   ├── Cart.java
│   ├── CartItem.java
│   └── Order.java
│
├── service
│   ├── ProductService.java
│   ├── CartService.java
│   └── OrderService.java
│
└── util
    └── InputUtil.java
```

### 各機能とServiceの対応

| 機能 | 担当クラス |
| --- | --- |
| 商品一覧表示 | `ProductService` |
| 商品検索 | `ProductService` |
| 商品詳細表示 | `ProductService` |
| カート登録 | `CartService` |
| カート一覧表示 | `CartService` |
| カート数量更新 | `CartService` |
| カート商品削除 | `CartService` |
| 注文確定 | `OrderService` |
